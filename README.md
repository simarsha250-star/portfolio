# Sasith Imarsha — Graphic Designer Portfolio

React 19 + Vite + TypeScript + Tailwind 3 + Framer Motion. Three.js (React Three Fiber) is used only for two
decorative, lazy-loaded scenes (hero ribbons, contact globe). The site works fully without WebGL.

## Run locally
```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # type-check + production build -> dist/
npm run preview
```

## Replace profile info
Everything editable lives in `src/data/`:
- `profile.ts` — name, bio, philosophy, portrait, stats. **Stats only show numbers if you set a verified `value`.**
- `skills.ts`, `experience.ts` — tools, categories, timeline (carried over from your original files; please verify).
- `projects.ts` — gallery entries (see the "How to add a project" comment in the file).
- `testimonials.ts` — leave empty until you have real, approved testimonials. While empty, the site shows "My Creative Approach".

Contact details come from environment variables, so nothing is invented. Copy `.env.example` to `.env.local`:
`VITE_CONTACT_EMAIL`, `VITE_WHATSAPP_NUMBER` (digits with country code), `VITE_INSTAGRAM_URL`, `VITE_BEHANCE_URL`.
Any method left empty is hidden everywhere (contact section and footer).

## Replace placeholder images
- Portrait: put your photo in `public/assets/portrait/` and update `profile.portrait` in `profile.ts`
  (recommended 800×1000, 4:5).
- Projects: add images to `public/assets/projects/` (cover 800×1000, details 1200×900), then edit the entry in
  `projects.ts` — set `isPlaceholder: false`, and `kind: 'commissioned'` only for real client work.
- The current files are labelled placeholders generated by `npm run placeholders` (reads `scripts/projects.json`).
- Social card: `public/assets/brand/og.jpg` (1200×630) — replace with your own artwork.

## Contact form via EmailJS (recommended — no server needed)
1. Sign up at emailjs.com → **Email Services** → add Gmail (or other) → copy the **Service ID**.
2. **Email Templates** → create a template. Set *To email* to your address and *Reply-To* to `{{reply_to}}`.
   Subject e.g. `Portfolio enquiry: {{project_type}} — {{from_name}}`. Body can use:
   `{{from_name}} {{from_email}} {{project_type}} {{budget}} {{message}}`. Copy the **Template ID**.
3. **Account → General** → copy the **Public Key**.
4. Put the three values in `.env.local` (`VITE_EMAILJS_SERVICE_ID`, `VITE_EMAILJS_TEMPLATE_ID`, `VITE_EMAILJS_PUBLIC_KEY`)
   and in Vercel → Environment Variables, then restart/redeploy.
Tip: in EmailJS → Account → Security, add your site domain (and `localhost`) if you restrict origins.

## Alternative: Vercel + Resend
The form posts to `/api/contact` (`api/contact.ts`). In Vercel → Project → Settings → Environment Variables add:
`RESEND_API_KEY`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL` (server-only, never prefix with `VITE_`).
Spam protection: hidden honeypot field + minimum fill time. Without those variables the API answers `not_configured`
and the form shows an honest "not sent" error (plus a mailto link if `VITE_CONTACT_EMAIL` is set). To use another
service (Formspree etc.) set `VITE_CONTACT_ENDPOINT` to an endpoint that returns `{ "ok": true }` on success.
`npm run dev` has no `/api` route; test the form with `vercel dev` or on a deployment.

## Deploy to Vercel
1. Push the project to GitHub. 2. Import it in Vercel (framework: Vite — detected automatically).
3. Add the environment variables above. 4. Deploy. Set `VITE_SITE_URL` to your final domain.
